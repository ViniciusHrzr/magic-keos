## v1 Requirements — Final Status

### Estabilidade e Fundação (FOUND)

- [x] **FOUND-01**: App persiste dados sem perda ao digitar (debounce no AsyncStorage)
  - **Outcome**: Debounce 500ms via useRef+setTimeout em CharacterContext; 8 .catch() handlers adicionados
  - **Plan**: 01-01
- [x] **FOUND-02**: App hidrata sem race condition (loading state antes de renderizar ficha)
  - **Outcome**: isLoaded guard em _layout.tsx; FichaScreen condicionada em isLoaded
  - **Plan**: 01-03
- [x] **FOUND-03**: Crashes de contexto isolados por error boundaries (não derruba app inteiro)
  - **Outcome**: ErrorBoundary global + por aba implementado
  - **Plan**: 01-02
- [x] **FOUND-04**: CharacterContext memoizado (sem re-renders desnecessários)
  - **Outcome**: Todos os 20 set* em useCallback([update]); contextValue em useMemo
  - **Plan**: 01-01

### Qualidade da Ficha (FICHA)

- [x] **FICHA-01**: Campos numéricos de IP não aceitam valores negativos
  - **Outcome**: IP BASE e BÔNUS substituídos por NumericStepper (min=0 default)
  - **Plan**: 02-01
- [x] **FICHA-02**: Veneno clampado entre 0–10 (regra: 10 = morte imediata)
  - **Outcome**: Pre-satisfied — VenenoTracker toggle UI já enforça 0–10; sem trabalho necessário
  - **Plan**: 02-01 (traceability only)
- [x] **FICHA-03**: Fonte PlanewalkerDings carrega antes da primeira renderização (sem flash de glyphs)
  - **Outcome**: Guard fontsLoaded em _layout.tsx; splash mantido até fonte pronta
  - **Plan**: 02-02
- [ ] **FICHA-04**: Ficha principal (index.tsx) dividida em componentes menores e reutilizáveis
  - **Outcome**: **DEFERRED to v1.1** — decisão explícita do usuário em 02-CONTEXT.md; index.tsx ainda > 300 linhas
  - **Plan**: N/A (deferred)

### Grimório e Mágicas (GRIM)

- [x] **GRIM-01**: Grimório (grimorio.tsx) dividido em componentes reutilizáveis
  - **Outcome**: StatPill extraído para components/rpg/; SpellDetailCard compartilhado entre grimório e magia
  - **Plans**: 03-01, 03-02
- [x] **GRIM-02**: Filtros do grimório persistem durante a sessão (não resetam ao navegar)
  - **Outcome**: Module-level vars (cor, grau, tipo) persistem enquanto processo vivo
  - **Plan**: 03-03

### Features de Mesa (MESA)

- [x] **MESA-01**: Aba "Regras" com referência in-session e campo "Notas" persistente
  - **Outcome**: 4ª aba com 8 seções estáticas + TextInput Notas via AsyncStorage
  - **Plan**: 04-01
- [x] **MESA-02**: Seletor de Proficiências estruturado (chips por CORPO/MENTE/ESPÍRITO)
  - **Outcome**: ProficienciasSection com chips togláveis agrupados por perícia; chaves `pericia:nome`
  - **Plan**: 04-02
- [x] **MESA-03**: Migração automática `proficiencias: string` → `proficiencias: string[]`
  - **Outcome**: Migration guard em CharacterContext: `typeof parsed.proficiencias === 'string' → []`
  - **Plan**: 04-02

### Qualidade de Código (CODE)

- [x] **CODE-01**: Constantes de cor e grau deduplicadas
  - **Outcome**: `constants/spell-constants.ts` criado; COLOR_HEX e GRAU_COLORS importados em magia.tsx e grimorio.tsx
  - **Plan**: 02-03
- [x] **CODE-02**: modal.tsx inacessível removido
  - **Outcome**: modal.tsx deletado; referência na tab bar removida
  - **Plan**: 02-02
- [x] **CODE-03**: explore.tsx re-export desnecessário corrigido
  - **Outcome**: explore.tsx deletado; tab registrada com `href: null` para ocultar
  - **Plan**: 02-02
