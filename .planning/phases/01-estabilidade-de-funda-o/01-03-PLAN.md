<objective>
Add an isLoaded boolean to CharacterContext that starts false and becomes true only after the AsyncStorage hydration useEffect completes (FOUND-02, D-04, D-05). Wire this flag into the three tab screens so they show a loading indicator instead of a zeroed character sheet during the cold-start hydration window.

Purpose: On a slow device or with large stored data, the app currently shows a blank/zeroed character sheet for a visible moment before AsyncStorage hydration completes. Users can also inadvertently trigger edits against the defaultCharacter during this window, which then get overwritten by the loaded data. After this plan, screens guard against this race condition.

Output: Modified CharacterContext.tsx (isLoaded state + interface field + contextValue inclusion); modified index.tsx, magia.tsx, grimorio.tsx (loading guard at screen root).

Note: This plan depends on Plan 01 (01-01) because Plan 01 adds the useMemo contextValue and useCallback set* wrapping — this plan adds isLoaded to that same contextValue and interface.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| AsyncStorage → CharacterProvider load() | Data hydrated from device storage; isLoaded gates rendering until this completes |
| isLoaded gate → screen rendering | Screens must not access character fields before isLoaded is true |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | isLoaded gate in screens | accept | isLoaded starts false and only transitions to true once — monotonic flag, cannot be reset to false by user action |
| T-03-02 | Denial of Service | isLoaded never becomes true | mitigate | setIsLoaded(true) is called in BOTH try and catch paths of load() — even if storage read fails, the catch path sets isLoaded=true so the app does not show a permanent loading spinner |
| T-03-03 | Spoofing | Race condition: user edits during loading | mitigate | Screens return ActivityIndicator when isLoaded===false — no interactive elements are rendered, so the user cannot trigger edits before hydration completes |
| T-03-04 | Information Disclosure | defaultCharacter visible during loading | mitigate | Fully mitigated: screens show ActivityIndicator (not character data) while isLoaded===false |
| T-03-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed — ActivityIndicator is a built-in React Native component |
</threat_model>
