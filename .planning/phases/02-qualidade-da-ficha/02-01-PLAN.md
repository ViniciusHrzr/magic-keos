| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | IP numeric input (user → AsyncStorage) | mitigate | NumericStepper clamps values to [min=0, max=999] before invoking `onChange`; the underlying `update()` writes only what the component emits. Negative values are unreachable from the UI path. |
| T-02-02 | Denial of Service | IP field render path | mitigate (existing) | Phase 1 already wrapped each tab screen in `<ErrorBoundary>` (commit 2045d41) so any render failure in InstanceBlock is contained to the Ficha tab and does not crash the whole app. No new code needed in this plan. |
| T-02-03 | Information Disclosure | IP field value | accept | IP values are non-secret game data stored in local AsyncStorage only. No PII, no network egress. App is local-only by design (REQUIREMENTS.md "Out of Scope"). |
| T-02-SC | Tampering | npm/pip/cargo installs | n/a | No new packages installed in this plan — NumericStepper already exists in the codebase (added before Phase 1). No supply-chain surface. |
