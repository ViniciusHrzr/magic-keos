<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| asset loader (expo-font) → render tree | The `useFonts` hook bridges the bundled `.otf` font file to the React tree; before resolution, render must be blocked to prevent fallback-glyph leakage |
| Expo Router file-system → registered routes | Files in `app/` become routes automatically; an unused template route (`modal`) is registered but has no entry point, and a re-export (`explore`) creates a phantom tab |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04 | Information Disclosure | Mana cost glyphs at first render | mitigate | `if (!fontsLoaded) return null;` blocks the entire render tree until PlanewalkerDings is loaded, eliminating the brief visual leak where the user sees fallback ASCII chars in place of mana glyphs (a confusing game-data display state). |
| T-02-05 | Tampering | Stale route registration (modal) | mitigate | Removing `<Stack.Screen name="modal" .../>` and deleting `app/modal.tsx` together prevents a runtime warning from Expo Router about an orphan route declaration; eliminates dead code path that an attacker (or future contributor) could repurpose for a non-reviewed screen. |
| T-02-06 | Spoofing | Phantom Explore tab duplicating Magia | mitigate | Deleting `app/(tabs)/explore.tsx` removes the duplicate-tab confusion. A user clicking "Explore" today lands on the Magia screen — a UX inconsistency that could be mistaken for a separate feature. After deletion, only the intended three tabs (Ficha, Magia, Grimório) exist. |
| T-02-07 | Denial of Service | Render of layout file | mitigate (existing) | Phase 1 plan 01-02 wrapped `<CharacterProvider>` in a global `<ErrorBoundary>` (commit 2045d41) at the top of `RootLayout`. The new `if (!fontsLoaded) return null;` runs BEFORE the ErrorBoundary is rendered; if `useFonts` itself were to throw synchronously, it would not be caught by the boundary. However, `useFonts` from `expo-font` is documented to return `[false, null]` on initial render and never throws synchronously — accepted risk. |
| T-02-SC | Tampering | npm/pip/cargo installs | n/a | No new packages installed — `expo-font` is already in `package.json` and was already imported. No supply-chain surface in this plan. |
</threat_model>
