<objective>
Add module-level filter persistence to `grimorio.tsx` so that the selected
color, grau, type, and search text filters survive tab navigation within
the session.

Purpose: React Native's tab navigator unmounts/remounts screens when navigating
away and back; local useState resets to defaults. Module-level variables (outside
the component function) retain their values for the app's lifetime, providing
zero-cost session persistence without AsyncStorage or a new Context provider
(per D-07, D-08, D-09).

Output:
- `app/(tabs)/grimorio.tsx` — four module-level vars added, useState initializers
  updated to read from them, four wrapper handlers added to keep them in sync.
</objective>

    Make the following edits to `app/(tabs)/grimorio.tsx` in order:

    STEP 1 — Add four module-level variables immediately above the `export default function GrimorioScreen()` line (but below the existing module-level constants like COLORS, TYPES, TYPE_LABELS):

    ```
    let _search = '';
    let _activeColor: SpellColor | null = null;
    let _activeGrau: number | null = null;
    let _activeType: SpellType | null = null;
    ```

    These are `let` (not `const`) because they will be mutated. They are initialized to the same defaults that the useState calls currently use. Note: `SpellColor` and `SpellType` are already imported at the top of the file.

    STEP 2 — Update the four useState calls inside `GrimorioScreen` to initialize from the module-level vars instead of hardcoded defaults:

    Change:
    - `const [search, setSearch] = useState('');` → `const [search, setSearch] = useState(_search);`
    - `const [activeColor, setActiveColor] = useState<SpellColor | null>(null);` → `const [activeColor, setActiveColor] = useState<SpellColor | null>(_activeColor);`
    - `const [activeGrau, setActiveGrau] = useState<number | null>(null);` → `const [activeGrau, setActiveGrau] = useState<number | null>(_activeGrau);`
    - `const [activeType, setActiveType] = useState<SpellType | null>(null);` → `const [activeType, setActiveType] = useState<SpellType | null>(_activeType);`

    The `expanded` and `selected` states are intentionally NOT persisted — they reset on navigation per normal tab behavior.

    STEP 3 — Wrap each filter setter so that it updates the module-level variable before calling the React state setter. Replace the four direct setter usages in the JSX:

    a. Search TextInput `onChangeText`: replace `onChangeText={setSearch}` with `onChangeText={v => { _search = v; setSearch(v); }}`

    b. Color filter onPress: replace `onPress={() => setActiveColor(activeColor === c ? null : c)}` with `onPress={() => { const next = activeColor === c ? null : c; _activeColor = next; setActiveColor(next); }}`

    c. Grau filter onPress: replace `onPress={() => setActiveGrau(activeGrau === g ? null : g)}` with `onPress={() => { const next = activeGrau === g ? null : g; _activeGrau = next; setActiveGrau(next); }}`

    d. Type filter onPress: replace `onPress={() => setActiveType(activeType === t ? null : t)}` with `onPress={() => { const next = activeType === t ? null : t; _activeType = next; setActiveType(next); }}`

    Do NOT change anything else in the file. Filter logic (filteredGroups useMemo), FlatList, Modal, and SpellDetailCard usage remain untouched.
