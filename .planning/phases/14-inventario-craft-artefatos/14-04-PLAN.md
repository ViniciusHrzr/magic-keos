Hexágono sem SVG — técnica de clip via View rotacionado:
A técnica padrão no RN sem SVG é usar duas Views rotacionadas. Um hexágono orientado "ponta em cima"
(pointy-top) com side=S tem dimensões: width = S*sqrt(3), height = S*2.
Para um hex de side=40: width≈69, height=80.
Alternativa mais simples: borderRadius agressivo em retângulo para simular hex arredondado.
Recomendado: usar a técnica de retângulo + borderRadius extremo — menos código, sem overflow issues:
  width: 64, height: 74, borderRadius: 18, rotateZ não necessário (hex flat-top visual via borderRadius)
O executor pode usar o estilo que produzir melhor resultado visual. O critério funcional é:
  - Forma claramente distinta de retângulo comum
  - Cor de borda de afinidade visível
  - Nome do item e dots de melhoria legíveis no estado colapsado
