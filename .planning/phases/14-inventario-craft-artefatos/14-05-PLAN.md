Reanimated v4 API (quebra de compatibilidade com v3):
```typescript
import Animated, {
  useSharedValue,
  useAnimatedStyle,
  withSpring,
  withTiming,
  runOnJS,
} from 'react-native-reanimated';
import { Gesture, GestureDetector } from 'react-native-gesture-handler';

// SharedValue para posição durante drag
const translateX = useSharedValue(0);
const translateY = useSharedValue(0);
const isDragging = useSharedValue(false);

// Pan gesture
const pan = Gesture.Pan()
  .onStart(() => { isDragging.value = true; })
  .onUpdate(e => {
    translateX.value = e.translationX;
    translateY.value = e.translationY;
  })
  .onEnd(() => {
    // Verificar drop target e chamar callback via runOnJS
    translateX.value = withSpring(0);
    translateY.value = withSpring(0);
    isDragging.value = false;
  });

const animStyle = useAnimatedStyle(() => ({
  transform: [
    { translateX: translateX.value },
    { translateY: translateY.value },
  ],
  opacity: isDragging.value ? 0.8 : 1,
  zIndex: isDragging.value ? 999 : 1,
}));
```

IMPORTANTE: Reanimated v4 NÃO usa o Babel plugin de worklets. Verificar se babel.config.js tem
'react-native-reanimated/plugin' — se não tiver, não adicionar (Expo 52 gerencia via Metro).

Estratégia de detecção de drop zone:
React Native não tem API nativa de drop zones. Estratégia: usar onLayout em cada DroppableHexSlot
para registrar as coordenadas absolutas (measure via ref), e no onEnd do Pan comparar a posição
do item arrastado com as bounds de cada hex slot.

Implementação simplificada (sem context global de drop zones):
  - DraggableGearCard: ao onEnd, chama callback onDropAttempt({item, gestureAbsoluteX, gestureAbsoluteY})
  - mochila.tsx: tem referências (useRef + measure) para cada DroppableHexSlot
  - mochila.tsx: onDropAttempt itera sobre hexRefs, mede bounds, decide qual slot recebeu o drop
  - Se compatível: setEquipamentoItem + removeInventarioItem
  - Se incompatível: animação de rejeição (withSpring de volta a 0)

   function handleDropAttempt(payload: { item: IStructuredGear; absoluteX: number; absoluteY: number }) {
     const { item, absoluteX, absoluteY } = payload;
     // Iterar sobre cada slot e medir bounds
     (Object.keys(hexRefs.current) as SlotKey[]).forEach(slot => {
       const ref = hexRefs.current[slot];
       if (!ref) return;
       ref.measureInWindow((x, y, w, h) => {
         const hitX = absoluteX >= x && absoluteX <= x + w;
         const hitY = absoluteY >= y && absoluteY <= y + h;
         if (hitX && hitY) {
           // Verificar compatibilidade de categoria
           if (!SLOT_ACCEPTS[slot].includes(item.type_equip)) return;
           // Equipar: setar no slot e remover do inventário
           setEquipamentoItem(slot, {
             nome: item.name,
             tipo: 'basico',
             melhorias: item.melhorias,
           });
           removeInventarioItem(item.id);
         }
       });
     });
   }
