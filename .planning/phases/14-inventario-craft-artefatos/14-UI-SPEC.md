## Interaction Contract

### Slot Card (Collapsible)

- Default state: collapsed. Shows `SLOT_LABEL` (10px, uppercase, textDark) + item name or "—" + melhoria count badge + chevron.
- Tap header: `LayoutAnimation.easeInEaseOut` plays, card body slides open.
- Only one slot expanded at a time (accordion pattern via `expandedSlot` state).
- Filled slot: border changes from `RPG.border` to `RPG.goldDim`.
- Empty slot: nome shows "—" in `RPG.textDark` at weight 400.
- Filled slot: nome shows item name in `RPG.gold` at weight 600.

### Item Picker Modal (EQP-01)

- Opens via "Escolher do livro" button inside expanded slotBody.
- Full-screen modal, `animationType="slide"`, dark background (`RPG.bg`).
- List filtered by slot type via `SLOT_ITEMS[slot]`.
- Selected item: left border 3px gold, `RPG.surface` background.
- Unselected items: hairline bottom border only.
- Close: ✕ top-right or Android back.

### Craft Melhoria Modal (CRAFT-01, CRAFT-02, CRAFT-03)

- Opens via "+ Adicionar Melhoria" button (disabled + 0.5 opacity when `melhorias.length >= 3`).
- Full-screen modal, same pattern as picker modal.
- Each row: colored dot (12×12 circle) + label text.
- Already-applied melhoria: `opacity: 0.5` + ✓ mark on the right. Tap does nothing (`activeOpacity: 1`).
- Available melhoria: tap calls `addMelhoria(slot, label)`, closes modal, badge appears in slotBody.
- Label not found in `MELHORIAS_POR_SLOT` falls back to `RPG.textMuted` for badge color.

### Melhoria Badge (CRAFT-03)

- Displayed as flex row with `flexWrap: 'wrap'` in `melhoriasList`.
- Each badge: colored border (1px) + colored label + × remove glyph.
- × taps `removeMelhoria(slot, idx)` — immutable filter, does not affect other badges.

### Tipo Toggle (ARTE-01)

- Pill button below melhoria controls.
- Default (básico): border `RPG.border`, text "Básico" in `RPG.textMuted`.
- Active (artefato): border `RPG.gold`, background `RPG.surfaceAlt`, text "Artefato ✦" in `RPG.gold`.
- Toggle clears `efeito` and `durabilidade` when reverting to "Básico".
- When artefato active: two extra fields appear below toggle:
  1. Multiline `TextInput` (minHeight 60px, `textAlignVertical: 'top'`): efeito ativável.
  2. `NumericStepper` (compact, min=0, label "Durabilidade"): durabilidade integer.
- Value `undefined` passed as `item.durabilidade ?? 0` to NumericStepper.

### Inventory Grid (INV-01, INV-02)

- 10 rows × 2 cells = 20 slots.
- Layout: manual array `Array.from({ length: 10 })` with two indices per row (View-based, not FlatList).
- Each cell: `flex: 1`, `flexDirection: 'row'`, `minHeight: 38`, RPG.surface background.
- TextInput: placeholder is the slot index number (1–20) in `RPG.textDark`.
- Clear button (✕): appears only when `slot.trim() !== ''`. Calls `setInventarioSlot(idx, '')`.
- `scrollEnabled` is implicit (parent ScrollView handles scroll — FlatList not used).

| Modal close glyph | ✕ | `accessibilityLabel="Fechar"` |
| Melhoria remove glyph | × | `accessibilityLabel="Remover melhoria"` |
| Craft applied glyph | ✓ | Display only — no interaction; no label needed |
| Loading state | ActivityIndicator (no text) — color: `RPG.gold` | — |

Destructive actions:
- "Remover item" (`clearSlot`): no confirmation dialog. Inline button inside expanded slot body. Soft destructive style (textMuted, bordered) — no red color, no confirmation required. Clears EquipItem to null including all melhorias.
- Inventory slot clear (✕): no confirmation. Inline per-slot, appears only when slot is non-empty.

Empty states:
- Slot with no item: em dash "—" in header, no slotBody content shown in collapsed view.
- Slot expanded with no item: shows name TextInput + "Escolher do livro" button only. No melhorias, no craft, no artefato controls.
- Inventory grid: all 20 slots always rendered with numeric placeholder — no empty state heading.

Error states: none in this phase. All operations are local-only AsyncStorage writes. No error UI defined. TypeScript strict + `migrate()` prevents schema corruption at the source.
