# Plan 17-01 — VidaBar Component

## Goal

Substituir a linha de 5 NumericSteppers horizontais da seção Vida por um componente `VidaBar` que exibe uma barra de progresso com 5 camadas visuais sobrepostas (Total, Atual, Necro, Armadura, Manto), mantendo os steppers de edição abaixo da barra.

## Context

**Schema existente** — `types/character.ts` já define:
```typescript
vida: {
  total: number;
  necro: number;
  atual: number;
  armadura: number;
  manto: number;
}
```

**Setter existente** — `store/CharacterContext.tsx` expõe `setVida(k: keyof Character['vida'], v: number)`.

**Bloco a substituir** — `app/(tabs)/index.tsx` linhas ~62–77:
```tsx
{/* ── VIDA ── */}
<SectionHeader title="Vida" />
<View style={styles.vidaRow}>
  {(['total', 'necro', 'atual', 'armadura', 'manto'] as const).map(k => (
    <View key={k} style={styles.vidaCell}>
      <Text style={styles.vidaIcon}>{vidaIcon(k)}</Text>
      <NumericStepper
        compact
        value={c.vida[k]}
        onChange={v => setVida(k, v)}
        color={k === 'armadura' || k === 'manto' ? RPG.textMuted : RPG.redLight}
      />
      <Text style={styles.vidaLabel}>{k}</Text>
    </View>
  ))}
</View>
```

**Paleta** — `constants/theme.ts`:
- `RPG.textDark` = `'#6a5540'` (neutro — fundo da barra = total)
- `RPG.red` = `'#c0392b'`
- `RPG.text` = `'#f0e6d3'`
- `RPG.textMuted` = `'#a89070'`
- `RPG.surface` = `'#181210'`
- `RPG.gold` = `'#c9a84c'`

**NumericStepper compact** — aceita props `compact`, `label`, `value`, `onChange`, `color`. No modo compact fica em linha (`flexDirection: 'row'`), altura 28px.

**Sem Skia** — VidaBar é React Native Views puro. Skia é reservado para Phase 18.

## Tasks

### Task 1 — Criar `components/rpg/VidaBar.tsx`

Criar o arquivo do zero com a seguinte estrutura:

**Props:**
```typescript
interface Props {
  vida: Character['vida'];
  onVidaChange: (k: keyof Character['vida'], v: number) => void;
}
```

**Imports necessários:**
- `React` from `'react'`
- `View, Text, StyleSheet` from `'react-native'`
- `RPG` from `'@/constants/theme'`
- `NumericStepper` from `'@/components/rpg/NumericStepper'`
- `Character` from `'@/types/character'`

**Lógica de cor da barra atual** — calcular `ratio = vida.total > 0 ? vida.atual / vida.total : 0`, então:
- `ratio >= 0.6` → `'#2d7a2d'` (verde)
- `ratio >= 0.3` → `'#a05020'` (âmbar)
- senão → `RPG.red` (vermelho crítico)

**Estrutura do componente — do exterior para interior:**

1. Wrapper externo (Manto): quando `vida.manto > 0`, envolver com `<View style={styles.mantoAura}>`. Quando `vida.manto === 0`, usar `<View style={styles.mantoAuraNone}>` (sem borda, sem padding extra).

2. Container da barra: `<View style={styles.barContainer}>` com `position: 'relative', height: 22, borderRadius: 4, overflow: 'hidden', backgroundColor: RPG.textDark`.

3. Dentro do container (absoluteFill):
   - Fill atual: `<View style={[styles.fill, { width: \`${Math.min(100, ratio * 100)}%\`, backgroundColor: actualColor }]} />` — usar `StyleSheet.absoluteFillObject` + override de width e backgroundColor.
   - Overlay necro: `<View style={[styles.fill, styles.necroOverlay, { width: \`${Math.min(100, vida.total > 0 ? (vida.necro / vida.total) * 100 : 0)}%\` }]} />` — `backgroundColor: 'rgba(100,0,160,0.5)'`.

4. Badge armadura: logo abaixo do container, renderizar `<View style={styles.armaduaBadge}><Text style={styles.armaduraBadgeText}>🛡 {vida.armadura}</Text></View>` quando `vida.armadura > 0`. Posicionado com `alignSelf: 'flex-start'`, `marginTop: 2`.

5. Stepper row: `<View style={styles.stepperRow}>` com 5 NumericSteppers compact, cada um envolto em `<View style={styles.stepperItem}><Text style={styles.stepperLabel}>{label}</Text><NumericStepper ... /></View>`.

Labels e cores dos steppers:
- `total` → label `'Total'`, color `RPG.textMuted`
- `atual` → label `'Atual'`, color `RPG.redLight` (importar `RPG.redLight = '#e74c3c'`)
- `necro` → label `'Necro'`, color `'#a060d0'`
- `armadura` → label `'Armadura'`, color `RPG.textMuted`
- `manto` → label `'Manto'`, color `'#00d4ff'`

**Estilos relevantes (StyleSheet.create):**
- `mantoAura`: `{ borderWidth: 2, borderColor: '#00d4ff', borderRadius: 6, padding: 2 }`
- `mantoAuraNone`: `{ borderWidth: 0, padding: 0 }` (ou simplesmente `{}` sem borda)
- `barContainer`: `{ height: 22, borderRadius: 4, overflow: 'hidden', backgroundColor: RPG.textDark }`
- `fill`: `{ ...StyleSheet.absoluteFillObject, width: '0%' }` (width sobrescrita inline)
- `necroOverlay`: `{ backgroundColor: 'rgba(100,0,160,0.5)' }`
- `stepperRow`: `{ flexDirection: 'row', flexWrap: 'wrap', gap: 4, marginTop: 8 }`
- `stepperItem`: `{ alignItems: 'center', gap: 2 }`
- `stepperLabel`: `{ color: RPG.textMuted, fontSize: 9, textTransform: 'uppercase' }`
- `armaduraBadge`: `{ alignSelf: 'flex-start', marginTop: 2, backgroundColor: RPG.surface, paddingHorizontal: 4, paddingVertical: 1, borderRadius: 3 }`
- `armaduraBadgeText`: `{ color: RPG.textMuted, fontSize: 11 }`
