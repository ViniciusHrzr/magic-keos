# Plan 17-02 — VenenoTracker Checkmarks

## Goal

Adicionar checkmarks visuais (✓) dentro de cada bolha preenchida do `VenenoTracker`, transformando o grid de slots de controle tátil em um tracker visual informativo — mantendo toda a lógica de toggle, estilos críticos e efeitos ativos intactos.

## Context

**Estado atual de `components/rpg/VenenoTracker.tsx`:**

O componente já existe com grid de 10 `TouchableOpacity` com bubbles circulares de 26×26px. A lógica de toggle funciona: tap em slot vazio preenche até aquele índice, tap em slot preenchido esvazia até aquele índice.

Estrutura relevante existente (linhas 24–36):
```tsx
{Array.from({ length: 10 }, (_, i) => (
  <TouchableOpacity
    key={i}
    onPress={() => onChange(i < value ? i : i + 1)}
    activeOpacity={0.7}
  >
    <View style={[
      styles.bubble,
      i < value && styles.filled,
      i < value && i >= 7 && styles.filledCritical,
    ]} />
  </TouchableOpacity>
))}
```

Estilos relevantes existentes:
- `bubble`: `width: 26, height: 26, borderRadius: 13` (círculo)
- `filled`: `backgroundColor: '#4a1a1a', borderColor: RPG.red`
- `filledCritical`: `backgroundColor: '#6b1010', borderColor: '#ff4444'` (slots 8–10, índices 7–9)

**Paleta:** `RPG.text = '#f0e6d3'` (creme claro — contrasta sobre ambos `filled` e `filledCritical`).

O arquivo importa `Text` de `'react-native'` — já disponível, sem novo import necessário.

## Tasks

### Task 1 — Adicionar checkmark dentro de cada bubble preenchida

Modificar apenas o `<View style={[styles.bubble, ...]}>` dentro do `TouchableOpacity`. A bubble passou a ser um container flexbox com conteúdo centralizado.

**Alteração na JSX** — dentro do `.map`, substituir:
```tsx
<View style={[
  styles.bubble,
  i < value && styles.filled,
  i < value && i >= 7 && styles.filledCritical,
]} />
```

Por:
```tsx
<View style={[
  styles.bubble,
  i < value && styles.filled,
  i < value && i >= 7 && styles.filledCritical,
]}>
  {i < value && <Text style={styles.checkmark}>✓</Text>}
</View>
```

Observações importantes:
- O checkmark é filho do `<View>` da bubble, não do `<TouchableOpacity>` diretamente.
- A condição `i < value` é a mesma já usada para `styles.filled` — consistente.
- Slots vazios (`i >= value`) não recebem o `<Text>` — permanecem bubbles limpas.

**Adicionar estilo `checkmark`** ao `StyleSheet.create` existente:
```typescript
checkmark: {
  color: RPG.text,
  fontSize: 14,
  textAlign: 'center',
  lineHeight: 26,
  fontWeight: 'bold',
},
```

O `lineHeight: 26` alinha verticalmente o ✓ dentro da bubble de 26px de altura.

**Adicionar `justifyContent` e `alignItems` ao estilo `bubble`** existente para centralizar o checkmark:
```typescript
bubble: {
  width: 26,
  height: 26,
  borderRadius: 13,
  borderWidth: 1.5,
  borderColor: RPG.textDark,
  backgroundColor: 'transparent',
  justifyContent: 'center',  // adicionar
  alignItems: 'center',      // adicionar
},
```

Estes dois campos não existem hoje; adicioná-los não quebra slots vazios (sem conteúdo filho, justifyContent/alignItems não têm efeito visual).

### Task 2 — TypeScript check

Executar `npx tsc --noEmit`. O único risco de tipo aqui é o `<Text>` ser renderizado dentro de um `<View>` — padrão válido em React Native, sem conflito de tipo esperado.

- Slots críticos (índices 7–9 quando preenchidos) mantêm o estilo `filledCritical` E exibem ✓.
- Slots vazios não exibem nenhum texto.
- Tap em qualquer slot mantém o comportamento de toggle inalterado (sem regressão).
- Os efeitos ativos abaixo do grid continuam aparecendo corretamente.
- `npx tsc --noEmit` passa sem erros.
