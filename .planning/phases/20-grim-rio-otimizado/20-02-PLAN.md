## Tasks

### GRIM-02-T0 — Pre-check: PlanewalkerDings font loaded

Confirm `PlanewalkerDings` is in `useFonts` in `app/_layout.tsx` before proceeding. Currently present at line 17:
```ts
PlanewalkerDings: require('@/assets/fonts/PlanewalkerDings.otf'),
```
If missing, do not proceed — pip characters will render as boxes with no TypeScript error.

### GRIM-02-T1 — Add COLOR_PIP constant

In `grimorio.tsx`, near `COLOR_LABELS` declaration, add:

```ts
const COLOR_PIP: Record<SpellColor, string> = {
  branco: 'a', verde: 'g', vermelho: 'd', preto: 'b', azul: 'u',
};
```

### GRIM-02-T2 — Update color filter button JSX

Replace the current color filter button content:

```tsx
// BEFORE
<Text style={[styles.filterText, { color: COLOR_HEX[c] }]}>{COLOR_LABELS[c]}</Text>

// AFTER
<Text style={[styles.pipText, { color: COLOR_HEX[c] }]}>{COLOR_PIP[c]}</Text>
```

Update the TouchableOpacity style: swap `filterBtn` (horizontal padding, no fixed size) for `pipBtn` (36×36 circular):

```tsx
// BEFORE
style={[styles.filterBtn, { borderColor: COLOR_HEX[c] }, activeColor === c && { backgroundColor: COLOR_HEX[c] + '33' }]}

// AFTER
style={[styles.pipBtn, { borderColor: COLOR_HEX[c] }, activeColor === c && { backgroundColor: COLOR_HEX[c] + '33' }]}
```

### GRIM-02-T3 — Add pipBtn and pipText styles; remove filterBtn/filterText

Search `grimorio.tsx` for all uses of `filterBtn` before deleting — confirm only the color filter row references it (grau/type row uses `filterBtn2`). Then in `StyleSheet.create`, remove `filterBtn` and `filterText`. Add:

```ts
pipBtn: {

  justifyContent: 'center',

### GRIM-02-T4 — Remove COLOR_LABELS constant

Delete `COLOR_LABELS` — no longer used after GRIM-02-T2.

### GRIM-02-T5 — Run TypeScript check

```

Fix any type errors.
