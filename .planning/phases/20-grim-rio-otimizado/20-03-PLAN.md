# Phase 20-03: Shared Element Spell Detail Screen — GRIM-03

**Phase:** 20-grim-rio-otimizado
**Sub-plan:** 03 of 03
**Goal:** Replace Modal slide-in with route-based navigation + Reanimated shared element transition (card expands from list position to fill screen).

---

## Pre-conditions

- 20-01 executed (FlashList, renderItem callback in place)
- 20-02 executed (pip filters applied)
- `react-native-reanimated` ~4.1.1 installed
- `SpellDetailCard` reusable as-is (accepts spell, onClose, magicas, onAddMagica)
- Root Stack at `app/_layout.tsx` manages screen transitions

## Goal

Tapping a spell row animates that row expanding to fill the screen (shared element). Detail screen shows SpellDetailCard with X button. Back navigation returns to grimório with reverse animation. No Modal in grimório.

---

## Implementation Strategy

**Spell data passing:** Module-level singleton at `store/selectedSpell.ts`. Set before `router.push`. Detail screen reads on mount. Avoids serializing large Spell objects through route params. Avoids circular imports between screen files.

**Shared element tags:** Each spell row's inner `Animated.View` gets `sharedTransitionTag={`spell-${spell.nome}`}`. Detail screen root `Animated.View` uses matching tag. Reanimated animates between matching tags on push/pop.

**Screen transition:** `animation: 'none'` on the Stack screen — lets the shared element drive the visual transition.

**FlashList recycling risk:** FlashList recycles native views. If recycling invalidates the shared element snapshot, Reanimated silently degrades to no animation. T4 requires on-device verification. If degraded, T4-FALLBACK activates (position-based animation).

**T4-FALLBACK (if shared element fails inside FlashList):**

If `sharedTransitionTag` silently degrades, fall back to a position-based entering animation:

1. Remove `sharedTransitionTag` from grimorio.tsx spell row — revert to plain `View` with `style={styles.spellRow}`.
2. Store the tapped card's screen position in the singleton before navigating:
   ```ts
   // In grimorio.tsx renderItem — spell branch:
   import { measure, useAnimatedRef } from 'react-native-reanimated';
   // Per-item animated ref approach is complex in recycled lists.
   // Simpler: use onLayout + store position directly.
   ```
   Actually for recycled lists, use `measure` via a regular ref on the `View`:
   ```tsx
   const rowRef = useRef<View>(null);
   // onPress:
   rowRef.current?.measure((x, y, width, height, pageX, pageY) => {
     selectedSpell.setOrigin({ x: pageX, y: pageY, width, height });
     selectedSpell.set(item.spell);
     router.push('/spell-detail');
   });
   ```
   Add `setOrigin` to the singleton (stores `{ x, y, width, height }`).
3. In `spell-detail.tsx`, read the origin and use `withTiming` to animate from origin position to full-screen on mount (entering animation):
   ```ts
   import { useAnimatedStyle, withTiming, withSpring } from 'react-native-reanimated';
   ```
   Animate `top`, `left`, `width`, `height` from origin to full screen using `useSharedValue`.

The fallback is more complex — pursue shared element first, activate fallback only if on-device test fails.

### GRIM-03-T7 — Create app/spell-detail.tsx

```tsx
import React from 'react';
import { StyleSheet } from 'react-native';
import Animated from 'react-native-reanimated';
import { useRouter } from 'expo-router';
import { SafeAreaView } from 'react-native-safe-area-context';
import { useCharacter } from '@/store/CharacterContext';
import { ErrorBoundary } from '@/components/rpg/ErrorBoundary';
import SpellDetailCard from '@/components/rpg/SpellDetailCard';
import { RPG } from '@/constants/theme';
import { selectedSpell } from '@/store/selectedSpell';

export default function SpellDetailScreen() {
  const router = useRouter();
  const { character: c, setMagica } = useCharacter();
  const spell = selectedSpell.get();

  if (!spell) {
    router.back();
    return null;
  }

  const tagKey = `spell-${spell.nome}`;

  return (
    <ErrorBoundary>
      <SafeAreaView style={styles.safe} edges={['top', 'bottom']}>
        <Animated.View style={styles.card} sharedTransitionTag={tagKey}>
          <SpellDetailCard
            spell={spell}
            onClose={() => router.back()}
            magicas={c.magicas}
            onAddMagica={setMagica}
          />
        </Animated.View>
      </SafeAreaView>
    </ErrorBoundary>
  );
}

const styles = StyleSheet.create({
  safe: { flex: 1, backgroundColor: RPG.bg },
  card: {
    flex: 1,
    backgroundColor: RPG.surface,
    borderTopWidth: 2,
    borderTopColor: RPG.gold,
  },
});
```
